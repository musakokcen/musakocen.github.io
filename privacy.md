# Privacy

This site does not use cookies and does not show ads.

## Analytics

I use [Umami](https://umami.is) to count page views. Umami does not set cookies, does not collect personal data, and does not track you across sites. It records the page you visited, the referring site, your browser, operating system, device type and country. Your IP address is used only to derive the country and is not stored. If your browser sends a "Do Not Track" signal, nothing is recorded.

The data is used only to see which posts people read. It is not shared or sold.

## Hosting

This site is hosted on GitHub Pages. GitHub may log your IP address when serving pages, for security and operations. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
